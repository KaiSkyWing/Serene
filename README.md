# ゲームタイトル: Serene

プレイ用リンク：[https://unityroom.com/games/naturildgame](https://unityroom.com/games/serenegame)

## 📝 プロジェクト概要

このゲームは、**ゲーム制作を始めて約4ヶ月後、1ヶ月かけて制作したアクションゲーム**です。
**企画・プログラム・ドット絵・演出すべてを個人で制作**しています。

ただし、完成しているわけではないので、ボスの実装などが不完全のままです。

---

## 🎯 ゲームの特徴

* 自作ドット絵によるレトロな世界観
* 酸素ゲージによる製薬の中での冒険

---

## 🕹️ 操作方法

素潜りをして魚を捕まえるゲームです

| 操作      | キー    |
| ------- | ----- |
| 移動      | WASD または矢印キー |
| 攻撃      | クリックで弾を発射 |
| ダッシュ      | Shift |

上部の白いものに触れると地上に戻ってきた判定となり、所持している魚などを持ち帰ることができます。

お店でそれらを換金できます。
